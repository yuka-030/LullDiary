# UI設計

## 方針

寝る前に使うことを意識し、温かみのある配色と本の表現を使用する。

画面の構成は `screens`、状態管理と操作は `lib`、表示部品は `components` に分ける。

## 配色

| 名前 | 色      | 用途               |
| ---- | ------- | ------------------ |
| bg   | #fbf2e7 | 基本背景           |
| bg2  | #f6e6d8 | 補助背景・境界     |
| main | #e8a24c | 主な操作           |
| glow | #f6c880 | 明るいアクセント   |
| sub  | #b98ca6 | 補助操作・本の表現 |
| txt  | #4a3b31 | 主な文字           |
| txt2 | #8c7768 | 補助文字           |

背景と同じ色だった枠付きボタンには、白を20%の不透明度で重ねる。すでに色の付いたボタンは元の背景を使用する。

矢印付きの「ホームにもどる」「本棚にもどる」は、背景のない文字の操作として表示する。

## ホーム

- 録音・入力画面を開く。
- 本棚を開く。
- アイコンだけの操作にも読み上げ用の名前を付ける。

## 録音・入力画面

### 音声入力

ハートとマイクの表現を使用する。

録音中は音量に応じた視覚的な変化と、残り時間を示す6個のドットを表示する。録音は最大3分で停止する。

停止後は、録り直しと文字起こしを選択できる。

### 認識結果モーダル

- 認識結果を順次表示する。
- 操作によって全文表示へ切り替えられる。
- 認識結果を編集できる。
- 「やめる」「物語にする」を選択できる。
- モーダル内でTabとShift+Tabのフォーカスを循環させる。
- Escapeで閉じる。

認識結果の確認と修正に使用するモーダルであり、表示文そのものを操作用ラベルに置き換えない。

### テキスト入力

- 案内文を入力欄の上部に常時表示する。
- 右下に「現在の文字数 / 120字」を表示する。
- 120字を超えた場合は、内容を保持してエラーを表示する。
- エラーは深みのある赤と文字の強調で表示する。
- 入力欄の内側に余分な枠を付けない。
- 空白だけの入力、上限超過、日本語変換中は送信できない。
- Windowsではフォーカス時に日本語入力への切り替えを試みる。

## 物語画面

本の表紙とページをめくる表現を経て、生成結果を表示する。

- 物語文を順次表示し、音声を読み上げる。
- 再生を一時停止・再開できる。
- 写真を1枚選択・変更・削除できる。
- 日記を保存できる。
- 生成に失敗した場合はエラーと再試行の操作を表示する。
- 音声生成だけに失敗した場合は物語文を残し、音声の再生成を選択できる。

## 本棚

年ごとに月の本を並べる。同じ月でも年を区別できる名前を付ける。

本棚が複数ページある場合は、次の操作を表示する。

- 本棚の左右中央に丸い矢印ボタン
- 本棚の下に「前の本棚」「ページ番号」「次の本棚」
- 先頭・末尾では対応する移動ボタンを無効化

丸い矢印は、ホバー時に背景を白、記号を茶色にする。

本棚が1ページだけの場合はページ切り替え操作を表示しない。「ホームにもどる」は本棚の下中央に表示する。

### 絞り込み

年月・シーン・感情を指定できる。

複数の感情を選んだ場合は、選択した感情をすべて含む日記を対象とする。条件を変更した場合は先頭の本棚ページへ戻る。

選択状態を確認でき、条件を解除できるようにする。

### 月の日記一覧

本の見開きに日付と物語文の一部を表示する。

複数ページある場合は「前のページ」「ページ番号」「次のページ」を表示する。日記を選択すると詳細画面を開く。

## 日記の詳細

物語文、写真、タグ、読み上げの操作を表示する。

編集では物語文、シーン、感情、写真を変更できる。物語文を変更した場合は、保存前に読み上げ音声を作り直す。

保存に失敗した場合はエラーを表示し、編集状態を維持する。

### 削除確認

- 削除前に確認モーダルを表示する。
- モーダルに名前と説明を付ける。
- 表示時にモーダル内へフォーカスを移す。
- TabとShift+Tabをモーダル内で循環させる。
- Escapeまたは取り消しで閉じた場合は元の操作へフォーカスを戻す。

## アクセシビリティの確認

キーボード操作、読み上げ用の名前、選択状態、無効状態、モーダルのフォーカス制御をテストする。

コントラストは自動検査に加えて目視でも確認する。影や薄い背景で視認性を補っている箇所は、自動検査の対象範囲と分けて扱う。

目視で読めることと、コントラスト基準への適合は同じ判定にしない。画面全体の基準適合を保証する記述は行わない。
